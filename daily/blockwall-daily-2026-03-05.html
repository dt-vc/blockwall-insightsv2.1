Crypto Scams Using ‘Powerful’ iPhone Exploit Kit: Google

News • Security • Score: 7/10

Google's Threat Intelligence Group uncovered the Coruna iOS exploit kit, a sophisticated tool with five exploit chains targeting iPhones on iOS 13.0 to 17.2.1, enabling remote code execution via malicious web content on scam crypto and gambling sites. This kit, originally from surveillance vendors and state actors like Russian spies targeting Ukrainians, now powers financially motivated crimes that steal cryptocurrency wallets, seed phrases, and apps such as Metamask. Institutional investors face elevated risks from these mass attacks on older iOS devices, underscoring the need for updated software, multi-layered defenses, and vigilant monitoring of mobile assets holding digital assets.
