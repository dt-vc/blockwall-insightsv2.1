OpenAI releases crypto security tool as Claude blamed for $2.7m Moonwell bug

Aleks Gilbert • Security • Score: 7/10

OpenAI and Paradigm released EVMbench on February 18, 2026, a benchmarking system designed to evaluate how AI agents detect, patch, and exploit vulnerabilities in Ethereum Virtual Machine smart contracts that currently secure over $100 billion in crypto assets. The tool draws from 120 high-risk vulnerabilities identified across 40 real security audits and includes scenarios from Paradigm's Tempo blockchain to reflect practical financial applications. Early testing reveals that AI models perform significantly better at exploiting vulnerabilities than at finding or fixing them, with OpenAI's GPT-5.3-Codex more than doubling its predecessor's exploit effectiveness while detection and patching capabilities remain incomplete. The release underscores growing institutional concern about AI-assisted smart contract development, particularly following recent incidents like the $2.7 million Moonwell bug caused by AI-generated code, and OpenAI is backing the initiative with $10 million in API credits for open-source and infrastructure security projects.

Dear Founders, Investors, and Friends, The crypto industry just crossed a critical threshold. With smart contracts now securing over $100 billion in assets, the security challenges we face have never been more urgent or consequential. This week, OpenAI and Paradigm released EVMbench, a groundbreaking benchmarking system that evaluates how AI agents detect, patch, and exploit vulnerabilities in Ethereum Virtual Machine smart contracts. Built on 120 real vulnerabilities from 40 audits plus scenarios from Paradigm's Tempo blockchain, this tool reflects the practical realities of financial applications we're building. The findings are sobering. AI models excel at exploiting vulnerabilities but struggle significantly with detection and patching. OpenAI's latest GPT-5.3-Codex more than doubled its predecessor's exploit effectiveness, yet detection and repair capabilities remain incomplete. This asymmetry matters enormously, especially following incidents like the $2.7 million Moonwell bug caused by AI-generated code. What does this mean for us? First, it signals that AI-assisted development requires robust human oversight and rigorous testing frameworks. Second, it validates the urgency of security-first infrastructure. Third, it demonstrates institutional commitment to responsible AI deployment in crypto, with OpenAI backing the initiative with $10 million in API credits for open-source security projects. Meanwhile, the Ethereum Foundation's 2026 priorities around security enhancements and improved cross-chain capabilities show the ecosystem is doubling down on foundational strength. The message is clear: as AI capabilities accelerate, so must our security standards and defensive infrastructure.
